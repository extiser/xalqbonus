# 01 — Окружение проекта

**Область:** infra
**Этап:** 0
**Блокируется:** ничем

## Задача

Поднять рабочее окружение нового проекта: git, Nuxt, Docker, локальная копия
продовой БД, Prisma поверх существующей схемы. После этой задачи проект
должен подниматься одной командой на чистой машине.

## Что прочитать

- `CLAUDE.md`
- `docs/decisions.md`
- `docs/analysis.md` — разделы 3 и 4

## Что реализовать

- [ ] `git init`, первый коммит. **До коммита проверить `git status`** — в `.gitignore`
      уже есть `.env` и `*.sql`, убедиться что они не попали в индекс
- [ ] Инициализировать Nuxt 4 проект поверх существующего дерева папок,
      не ломая `docs/`, `issues/`, `product/`
- [ ] Установить зависимости из `docs/decisions.md`, **дописать в спеку точные версии**
- [ ] `docker compose up -d`, убедиться что Postgres на 5433 и Redis на 6380 живы
- [ ] Восстановить дамп `../xalqbonusbot/backup-db-2026-08-15-1258.sql` в локальную БД
- [ ] `prisma db pull` — снять схему с восстановленной базы
- [ ] `prisma generate`, проверить что клиент собирается
- [ ] Заполнить `prisma/schema.prisma` фактической схемой после introspection
- [ ] Настроить `npm run typecheck`, `npm run test` (Vitest), линтер

## Критерий готовности

На чистой машине: `cp .env.example .env` → `docker compose up -d` → восстановление
дампа → `npm install` → `npm run dev` поднимает приложение, `npx prisma studio`
показывает 4 062 водителя и 1 162 756 поездок.

`npm run typecheck` и `npm run test` отрабатывают без ошибок (тестов пока может
не быть — важно, что команды настроены).

# 02 — Разведка Yandex Fleet API

**Область:** sync
**Этап:** 1
**Блокируется:** 01

## Задача

Проверить на живом API ключевое допущение, на котором построена вся новая схема
синхронизации: что `/v1/parks/orders/list` работает **без** `driver_profile`
в запросе, умеет фильтровать по `ended_at` и возвращает в каждом заказе
идентификатор водителя.

Пока это не проверено, план синхронизации из `docs/analysis.md` §2 и §6 —
гипотеза, построенная на чужой обёртке к этому API.

## Что прочитать

- `docs/analysis.md` — разделы 1.1, 2, 6
- `../xalqbonusbot/controllers/yandexApi.js` — как вызывается сейчас
- `../xalqbonusbot/docs/05-integrations.md`

## Что реализовать

- [ ] Скрипт-разведчик (одноразовый, в `scripts/`, не часть приложения)
- [ ] Запрос `orders/list` **без** `driver_profile`, фильтр по `park.order.ended_at`,
      узкое окно (час), `limit: 500`
- [ ] Зафиксировать: принимается ли запрос, сколько заказов вернулось,
      есть ли в каждом заказе `driver_profile_id` (или как он там называется)
- [ ] Проверить пагинацию `cursor` в этом режиме — работает ли, как выглядит
- [ ] Проверить, что возвращается для заказов в промежуточных статусах:
      попадают ли они в выборку по `ended_at`, что в поле `ended_at`
- [ ] Замерить: сколько заказов приходит за час/сутки реального времени парка
- [ ] Записать полный контракт в `docs/yandex-fleet.md`:
      эндпоинт, тело запроса, форма ответа с примером, поля, лимиты, поведение ошибок

## Критерий готовности

`docs/yandex-fleet.md` содержит проверенный на живом API контракт
с реальным примером ответа. На вопрос «можно ли забирать заказы всего парка
по `ended_at` и понимать, кому начислять» есть однозначный ответ: да или нет.

Если **нет** — в спеке зафиксировано, что именно не работает, и предложены варианты.

## Не делать

- Не писать адаптер и воркер — это задача 04
- Не трогать базу, ничего не сохранять
- Не запускать по всему парку на широком окне: узкие окна, минимум запросов.
  Лимит общий с продом, лишняя нагрузка ударит по работающему боту

## Внимание

Задача требует **боевых ключей Fleet API** — это единственное исключение
из правила «прод не трогаем», и оно ограничено чтением узких окон.
Согласовать запуск с Русланом до первого запроса.

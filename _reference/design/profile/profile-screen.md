# Раздел «Профиль» — кто залогинен и настройки водителя

Словесное описание к макету. Файлы рядом:

- `profile-screen.html` — **экран целиком**: карточка человека, настройки, сброс сессии
  и шторка подтверждения сброса (открывается кнопкой)
- `../artboard/language-sheet.html` и `../artboard/language-sheet.md` — **шторка языка**, открывается
  строкой «Язык». Экран под ней — копия этого, правится здесь
- `../artboard/section-bar.html` — шапка раздела, общая у всех разделов. Правится там

Нарисован 23-09-2026, сессия 53, по словам Руслана. Строка «Уведомления» снята 23-09-2026,
сессия 54 (T54).

## Зачем экран

Водители работают «друг за друга», и у стойки менеджер тратит время, чтобы понять, чья
учётка перед ним. Профиль отвечает на это одним экраном: кто это, по каким номерам его
искать и сверять. Вход — по аватару на главной.

## Карточка человека

Верх — аватар и ФИО в две строки: фамилия первой, имя и отчество второй. ФИО не режется,
а переносится: его сверяют с документом в руках. Отчества нет — вторая строка короче,
раскладка не меняется.

Под ним пять полей строками «подпись слева, значение справа». Значения моноширинными
цифрами: менеджер сверяет их знак за знаком с тем, что называет водитель.

| Поле | Откуда | Если нет |
|---|---|---|
| Телефон | `xb.profile_phones`, активная строка | «нет в парке» серым: у нерабочей учётки парк телефон не отдаёт. Серым, а не алым — это не ошибка |
| Telegram ID | `xb.telegram_links.telegram_chat_id` активной привязки | — |
| Позывной | `xb.park_profiles.callsign`, активная учётка | — |
| Номер ВУ | `xb.person_licenses.number_raw`, активная строка | — |

ФИО — из `xb.park_profiles` (`last_name`, `first_name`, `middle_name`).

По данным на 23-09-2026 (запрос сессии 53): телефон есть у 3 747 из 4 066 участников,
у 319 учётка нерабочая (294 `fired`, 26 `not_working`) — у них строка «нет в парке».

**Номер ВУ — последние четыре знака и глазик.** Глазик раскрывает номер целиком. Номер
приезжает с экраном целиком, секретом он не считается: маска — «для вида надёжности»
(Руслан, 23-09-2026).

**Машины в карточке нет** — решение Руслана, сессия 53.

## Настройки

Одна строка — «Язык» со значением и шевроном, открывает шторку языка. Настройка у водителя
одна: выключатель уведомлений убран из приложения (T54), язык — единственное, что водитель
меняет сам.

## Сброс сессии

Вторичная алая кнопка L отдельно под настройками, с увеличенным отступом сверху — чтобы
по ней не попадали, листая настройки. Это не настройка, поэтому не строка в группе.

Зачем: иногда в приложении что-то «закешировалось», и водителю нужно зайти заново.
Нажатие открывает шторку подтверждения по эталону шторок: «Сбросить сессию?», пояснение,
«Сбросить» алой L, «Отменить» серой L.

**В базе не меняется ничего** — привязка не закрывается, учётка та же. Закрытие отбилось бы
при повторном входе: `registerDriverByContact` не пускает пару «человек + чат», закрытую
в истории. Сброс — только на стороне приложения:

1. `POST /api/miniapp/reset` — бот шлёт в чат приветствие с кнопкой «Открыть приложение»,
   как на /start, на языке из `person_settings`
2. стереть копию `initData` из `sessionStorage` (ключ `xalqbonus:init-data`)
3. закрыть окно — `Telegram.WebApp.close()`

Ручка не ответила — окно закрывается всё равно, водитель нажмёт /start сам. Задача — T53.

- **Ручка записи языка** — `person_settings.language`, заводится по `#134`
- **Ручка сброса** `POST /api/miniapp/reset` — T53

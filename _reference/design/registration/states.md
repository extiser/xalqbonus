# Служебные экраны приложения — загрузка и заглушки

Описание словами к макетам. Файлы лежат рядом:

- `state-loading.html` — **загрузка**: логотип и под ним круглый загрузчик
- `state-loading-variants.html` — **лист вариантов загрузчика**, А–Е. Выбран Е
- `state-load-failed.html` — **не удалось загрузить**, есть кнопка «Обновить»
- `state-not-telegram.html` — **открыто не из Telegram**, кнопки нет
- `state-outdated-telegram.html` — **устаревший Telegram**, кнопки нет

Макеты нарисованы 23-09-2026 в сессии 54. Изменения в коде собраны в `tasks/T55-registration-flow-contract.md`, раздел «Служебные экраны».

## Что общего у всех экранов

- Фон живой, взят с главной без правок
- Три заглушки устроены как экраны регистрации: логотип белым слева вверху, текст выровнен по левому краю, заголовок Manrope 28/800 (`registration.md`, «Общее для всех экранов»). Загрузка устроена иначе: логотип стоит по центру
- Все заглушки — это `failWith` в `app/pages/app.vue`: текст плюс, если повтор имеет смысл, кнопка «Обновить». Сейчас это одна строка алым по центру, макеты заменяют её экраном

## Загрузка

Этот экран показывается от открытия приложения до ответа `/api/miniapp/me`. Сейчас на его месте многоточие по центру (`app.vue`, `stage === 'loading'`).

- Логотип 96 px по центру, под ним с отступом 22 px белое кольцо: 22 px внутри, линия 2.5 — снаружи 27 px, как в CSS макета (принято Русланом по ревью PR #195, 24-09-2026); крутится с оборотом за 0.9 с
- **Логотип и кольцо появляются и уходят вместе, одним блоком.** Вход занимает 0.4 с, выход 0.3 с, прозрачность меняется вместе с масштабом 96 → 100%. Фон не анимируется (Руслан, 23-09-2026)
- Следующий экран показывается, когда блок полностью ушёл: без этого загрузчик обрывается на полуобороте
- Кольцо белое, а не гранатовое: гранатовый на экране — цвет действия, а загрузка ничего не просит нажать. Полоски из дневной цели акции (А–Г на листе) тоже пробовали. Выбран круглый, «пока в приложении юзаем Е»
- При включённом «уменьшении движения» кольцо не крутится, а блок только проявляется, без масштаба
- На макете встроен цикл «вход → крутится → выход → пауза», чтобы движение было видно. В приложении цикла нет

## Не удалось загрузить

Этот экран показывается, когда запрос состояния не прошёл (`loadState`, `failWith(LOAD_FAILED)`) и когда не прошла сама отправка номера (`register`, catch).

- Экран двуязычный: чей это человек, на этом этапе ещё неизвестно. Узбекский идёт первым и крупнее, русский тише
- «Yuklab bo'lmadi» — «Ma'lumotlarni yuklab bo'lmadi. / Qaytadan urinib ko'ring.»
- «Не удалось загрузить» — «Не удалось загрузить данные. / Попробуйте ещё раз.» Вторая фраза в обоих языках начинается с новой строки
- Внизу кнопка «Yangilash / Обновить» (`RETRY_LABEL`). Она повторяет тот же запрос, что при первом открытии (`retry`)

## Открыто не из Telegram

Этот экран показывается, когда в странице нет подписанного `initData` (`hasSignedInitData`, `failWith(OPEN_FROM_TELEGRAM, { retryable: false })`).

- Экран двуязычный
- «Telegram orqali oching» — «Ilova faqat Telegram ichida ishlaydi. / Botni oching va «Ilovani ochish» tugmasini bosing.»
- «Откройте через Telegram» — «Приложение работает только внутри Telegram. / Откройте бота и нажмите «Открыть приложение».»
- Название кнопки совпадает с кнопкой бота `button_open_app` в `server/bot/texts.ts`, но без эмодзи. Название стоит в начале строки, чтобы не остаться на ней одним словом
- Кнопки нет: повтор дал бы тот же ответ

## Устаревший Telegram

Этот экран показывается, когда водитель нажал «Отправить номер», а у клиента нет `requestContact`, то есть клиент старее Bot API 6.9 (`share()`, текст `outdatedClient` ← `client_outdated`).

- Экран на **одном** языке — на том, что выбран при регистрации: нажать кнопку можно только с шага 2, где язык уже известен
- «Обновите Telegram» — «Ваш Telegram устарел: поделиться номером внутри приложения в нём нельзя.» Вторым абзацем: «Обновите Telegram до последней версии и откройте приложение снова.»
- **Кнопки нет.** Сегодня она есть: `failWith` по умолчанию делает заглушку `retryable`. Но «Обновить» перечитывает `/me`, вернёт экран регистрации, и водитель упрётся в то же окно. Чинится это только обновлением клиента

## Что не нарисовано

Отказ двери у сотрудника (`employee_denied`, `reportDoorDenial`) тоже проходит через `failWith`, с текстом от сервера. Отдельного макета у него нет: по устройству это экран «Не удалось загрузить» с другим текстом.

## Что меняется в коде

- загрузка: логотип и кольцо вместо многоточия, появление и уход одним блоком, смена экрана после ухода
- заглушки: экран с логотипом, заголовком и текстом вместо одной алой строки. Тексты заглушек делятся на заголовок и текст
- новый текст `OPEN_FROM_TELEGRAM`; `client_outdated` — из двух абзацев
- устаревший клиент — `retryable: false`

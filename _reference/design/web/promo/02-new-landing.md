# Промо — новая метка рекламы: выбор лендинга

Сессия 109, 11-10-2026. Файл `02-new-landing.html` рядом, скопирован с `02-new-ad-entry.html`. Задача — T131, задача 7.

## На каких решениях стоит экран

- У метки один лендинг, в ссылке только код метки (сессия 105)
- Поле «Лендинг» — только у рекламы в Telegram со входом «Приложение»; со входом «Чат бота» заявку ведёт бот, поля нет (сессия 109)
- По умолчанию — «Экран заявки» из #456 (сессия 106)
- В выборе нет лендингов из архива и не прошедших проверку (сессия 109)
- Сменить лендинг — до первого перехода по метке, после — нельзя: воронка не смешивает лендинги (сессии 105, 109)

## Что показано

- Окно «Новая метка»: носитель «Реклама в Telegram», вход «Приложение», ссылка `t.me/xalqbonusbot?startapp=<код>`
- Под входом — поле **«Лендинг»**, обязательное, выбор из списка. Список открыт: «Экран заявки» с пометкой «по умолчанию», «Машина парка» — выбран, «Своя машина, 3 %». «Своя машина, бонус 300» в списке нет — не прошёл проверку (`04-landings.html`); «Первый тест, сентябрь» нет — в архиве
- Под полем: «Что увидит человек, открывший приложение по метке. Сменить лендинг можно до первого перехода по метке.» — правило поля, которое работает в коде, а не справка
- В макете щёлкается: смена носителя или входа прячет поле, нажатие на поле открывает и закрывает список

## Раскладка

- ноутбук — окно 560 по центру, список открывается под полем поверх следующих полей
- телефон — окно во весь экран, список во всю ширину поля

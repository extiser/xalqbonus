# Промо — новая метка рекламы: выбор входа

Сессия 108, 11-10-2026. Файл — `02-new-ad-entry.html` рядом, скопирован с `02-new.html`. Задача — T131, задача 3 (заявка в чате бота): чтобы двумя метками сравнить заявку в приложении и заявку в чате, у метки рекламы нужен выбор, куда ведёт ссылка.

## Что показано

- Окно «Новая метка», носитель «Реклама в Telegram» выбран. В ряду носителей он стоит перед «Другое», как в коде (`PROMO_MEDIUMS`); в `02-new.html` его ещё не было — он появился в #456
- Под носителем — новое поле **«Вход»**, две пилюли: «Приложение» и «Чат бота». Видно только у носителя «Реклама в Telegram»: остальные носители всегда ведут в чат бота, выбирать там нечего
- Поле «Ссылка» меняется по входу: «Приложение» — `t.me/xalqbonusbot?startapp=<код>`, «Чат бота» — `t.me/xalqbonusbot?start=<код>`. Код тот же, новый не запрашивается
- Пилюли в макете щёлкаются: смена носителя прячет и показывает «Вход», смена входа меняет ссылку

## Правила за экраном

- **Вход после создания не меняется** (Руслан, сессия 108): ссылка уже стоит в объявлении. Нужен другой вход — новая метка
- **Вход решает только ссылку** (Руслан, сессия 108): заявку принимают обе двери у любой метки рекламы. Открыл чат по метке «Приложение» — бот всё равно ведёт заявку в чате; открыл приложение по метке «Чат бота» — приложение показывает форму
- Поле обязательное, как носитель

## Принято

- Экран принят (Руслан, сессия 108, 11-10-2026: «угу, вроде ок»)
- **По умолчанию выбрано «Приложение»** (Руслан, сессия 108): так ведут себя метки рекламы сейчас, и уже заведённые метки получают его же. В макете нарочно выбран «Чат бота», чтобы было видно, как меняется ссылка

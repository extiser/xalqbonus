# Снимок макетов веба

Копия утверждённых макетов веба из планировочной папки. Макеты здесь не правятся: новая версия приезжает новым снимком.

- `codex.html` + `codex.md` — кодекс веба в стиле бенто: палитра и токены веба, шкала шрифтов, сетка 12 колонок, плитки, график, каркас с меню слева, меню аккаунта, меню на телефоне панелью внизу, подсказка метрики, формы (снят 05-10-2026)
- `icons-compare.md` — набор значков меню (Phosphor Duotone) и таблица «пункт меню → значок»; четыре набора сравнивались, выбран один (04-10-2026)
- `dashboard/01-money.html` + `.md` — дашборд, вкладка «Деньги» (04-10-2026)
- `dashboard/02-levers.html` + `.md` — дашборд, вкладка «Рычаги» (04-10-2026)
- `dashboard/03-depth.html` + `.md` — дашборд, вкладка «Глубина» (04-10-2026)
- `dashboard/03-depth-newbies.html` + `03-depth-newbies-states.html` — «Глубина», новички вместо таблицы наборов: эталон на закрытом апреле 2026 и все состояния; описание — `dashboard/03-depth.md` → «Новички…» (06-10-2026)
- `dashboard/conclusions.md` — выводы словами под плитками дашборда: правила, формулировки, пороги; эталон для теста (`docs/infra.md` → «Тесты», четвёртое исключение) (05-10-2026)
- `promo/01-list.html`, `02-new.html`, `03-card.html` + `01-list.md`, `03-card.md` — раздел «Промо»: список меток, окно «Новая метка», карточка метки (05-10-2026)
- `promo/02-new-ad-entry.html`, `03-card-ad-entry.html`, `01-list-ad-entry.html` + `.md` к каждому — вход у метки рекламы в Telegram: выбор «Приложение / Чат бота» в окне «Новая метка», вход в строке карточки и под носителем в списке (11-10-2026)

Правила:

- Вёрстка идёт строго по макету: размеры, кегли, отступы, цвета и значки — из CSS и разметки макета. Цифры на экранах условные: они показывают устройство плитки, а не данные парка
- Токены веба — свои, не `--color-xb-*` водительского Mini App; общие только смысловые цвета. Подробности — `codex.md`
- Меню слева, меню аккаунта и панель меню на телефоне — один компонент на все разделы веба. Сначала он встаёт на дашборд, остальные разделы переезжают на ту же раскладку позже
- Скрипт в конце макетов только открывает и закрывает меню аккаунта и подсказку метрики, чтобы их можно было потрогать; это не образец кода
- Номера `T…` в описаниях — задачи планировочной папки, ссылки `inspiration/` и сессии — тоже оттуда. Туда не ходить: всё нужное для работы лежит здесь и в теле issue

# Выбор месяца на дашборде

Повод: у пилюли месяца только стрелки «‹ ›» — на много месяцев назад неудобно. Все три файла — копии `02-levers.html`, меняется только шапка с пилюлей месяца. Правила — `../codex.md` → «Выбор месяца».

## `month-picker-list.html` — принятый вид, список открыт

- Название месяца в пилюле — кнопка со стрелкой вниз; стрелки «‹ ›» остаются
- Окно под пилюлей, по правому краю, на приподнятой поверхности, ширина 240: подзаголовок года (11 / 600 серым), месяцы полными названиями (14 / 500), новые сверху; только месяцы с данными
- Выбранный — подложка циан 12 %, контур циан 45 %, текст циан; у идущего месяца справа «идёт»
- Высота окна до 420, дальше прокрутка внутри окна; внизу через линию — «Данные — с октября 2025»
- Выбор месяца закрывает окно и меняет `?month=`, как стрелки

## `month-picker-today.html` — выбран прошлый месяц, список закрыт

- Слева от пилюли — ссылка «К октябрю 2026 →»: текст 14 / 600 цветом `title`, стрелка 14 px, без подложки и контура; при наведении — циан
- Видна, только когда выбран не текущий месяц; подпись — текущий месяц и год
- Нажатие — переход к текущему месяцу, тот же, что выбор в списке

## `month-picker.html` — запасной вариант, не принят

Сетка 3 × 4 месяцев по годам со стрелками года; месяцы вне данных — серые и не нажимаются. Отложена: при одном–двух годах данных сетка наполовину пустая. Пригодится, когда список станет длинным — окно и кнопка у вариантов общие.

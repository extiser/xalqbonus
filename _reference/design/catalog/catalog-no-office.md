# Каталог без офиса на входе — офис выбирается при первом добавлении

Задача T70, сессия 61, 25-09-2026. Все четыре экрана приняты Русланом в тот же день; состояние 2а — сессия 62. Файлы рядом:

1. `catalog-no-office.html` — каталог без офиса
2. `catalog-pick-office.html` — шторка «Где заберёте?» на первом «+»
3. `catalog-office-picked.html` — витрина выбранного офиса
4. `catalog-exit-sheet.html` — выход из каталога с непустой корзиной

Меняет путь из `catalog.md` («Путь водителя»): там каталог открывался шторкой выбора офиса. Витрина, счётчики, корзина, подтверждение и оформление — прежние (`catalog.md`, `catalog-showcase.html`, `catalog-confirm.html`).

## Зачем

Нажатие на товар на главной открывало шторку выбора офиса — водитель нажал на товар и ждёт увидеть товар. Шторка товара с офисами внутри этого не лечила: «тот же выбор офиса, просто добавили показ товара» (Руслан). Офис нужен только в момент, когда товар кладут в корзину, — тогда его и спрашиваем.

## 1. Каталог без офиса

- Вход — «Обменять баллы», «Весь каталог» и нажатие на товар в блоке каталога главной (тогда витрина прокручена к этому товару)
- Все товары, которые есть хотя бы в одном работающем офисе
- Строка офиса — на своём месте: «Офис · Выбрать». «Выбрать» открывает шторку «Где заберёте?» со всеми офисами
- Пилюли остатка «N шт» на фото нет — остаток зависит от офиса. Скидка остаётся
- Корзина пуста — итога и «Оформить» нет. Счётчик «− 0 +» обычный

## 2. Шторка «Где заберёте?»

- Первый «+» на любом товаре. Показывается **всегда**, даже если офис один (Руслан)
- Только офисы, где этот товар есть, у каждого — его остаток «5 шт». Отметка ставится нажатием
- Подзаголовок — правило до выбора: «Один заказ — один офис: дальше в корзину добавляются товары только из него». Названия товара нет — оно бывает очень длинным (Руслан)
- «Добавить в корзину» гранатом — гаснет, пока офис не отмечен; «Отменить» серой — ничего не добавлено, офис не выбран
- Через «Выбрать» в строке офиса: все офисы, без остатков, кнопка «Выбрать»; корзина остаётся пустой

### 2а. Товар закончился, пока выбирали — `catalog-pick-office-sold-out.html`

Сессия 62, 25-09-2026. «Добавить в корзину» сначала читает витрину отмеченного офиса. Товар там есть — шторка закрывается, товар в корзине. Товара нет — шторка **остаётся**: водитель не попадает на витрину, где его товар приглушён в конце (Руслан: «выбрал вроде, а он потерялся»).

- Над кнопками — строка алым мягким «Этот товар в Кадышева закончился — выберите другой офис»: то же место и вид, что «Корзина очистится» в шторке смены офиса
- Остатки в шторке обновлены: офис с нулём ушёл из списка, отметка снята, «Добавить в корзину» погашена до новой отметки
- Товар кончился везде — строка «Этот товар закончился», список пуст, остаётся «Отменить» (отдельным листом не рисовалось)

## 3. Витрина выбранного офиса

- Товар в корзине, офис закреплён. Строка «Офис · Кадышева · Сменить» закреплена под шапкой и при прокрутке не уезжает
- Товары, которых в офисе нет, **не прячутся**: фото серое, цена и название блёклые, вместо счётчика пунктирная плашка «Нет в Кадышева». Каталог не отфильтровывается молча (Руслан). Они стоят в конце витрины — сверху всё, что можно взять
- Тултип под строкой офиса — сразу после выбора, один раз: «Показаны товары офиса Кадышева. Один заказ — один офис: чтобы взять товар из другого, смените офис». Лежит поверх витрины, контент не сдвигает, уголок указывает на имя офиса. Гаснет при прокрутке, по крестику, по нажатию в любом месте, при смене офиса
- Цвет тултипа — приглушённый гранат из набора: подложка `#2D1B25` (гранат 12 % поверх `#14171D`), рамка гранат 45 %, текст `#E4E8EE`, офис белым жирным, крестик `#FF7089` на гранате 16 %. Золото — цвет наград, в каталоге выбивалось
- «Сменить» — шторка смены офиса, как сейчас, с предупреждением «Корзина очистится»

## 4. Выход с непустой корзиной

- Корзину не запоминаем: иначе висящих корзин будет вагон (Руслан). Уход из каталога её стирает
- На «Назад» в шапке и системный жест «назад» при непустой корзине — шторка: «Выйти из каталога?», «Товары из корзины не сохранятся.» (15/400 светлым, как подзаголовок шторки отмены заказа), «Остаться» гранатом, «Выйти» серой. Пустая корзина — уход без вопроса

## Что меняется в коде

- Общая витрина без офиса — новая ручка: товары с остатком хотя бы в одном работающем офисе
- «Где есть товар» — новая ручка: работающие офисы с остатком по одному товару
- Витрина офиса отдаёт и товары, которых в офисе нет, — с признаком для приглушения; порядок: доступные, затем отсутствующие
- Экран каталога: состояние «офис не выбран»; первый «+» — шторка вместо прибавления; строка офиса закреплённая; тултип; шторка выхода
- Нажатие на товар на главной — каталог без офиса, прокрученный к товару

# Снимок макетов Mini App

Копия утверждённых макетов из планировочной папки. Снята 24-09-2026 под регистрацию и служебные экраны. Макеты здесь не правятся: новая версия приезжает новым снимком.

- `registration/` — макеты экранов (HTML) и описание словами (`.md`) к ним
- `system.md` — шкала шрифтов, правило цвета в строке, общие правила дизайна
- `motion.md` — движение: живой фон и анимации
- `assets/` — картинки, которые нужны коду отдельным файлом

Правила:

- Вёрстка идёт строго по макету: размеры, кегли, отступы, цвета и движение — из CSS макета, тексты — из словаря `T` в скрипте макета, если он есть
- Макет приоритетнее уже свёрстанных компонентов `app/components/**/next/`: элемент тот же, а выглядит иначе — компонент правится под макет
- Ссылки в описаниях на `memory/`, `tasks/`, `product/`, `../covers/` и другие файлы вне этой папки ведут в планировочную папку. Туда не ходить: всё нужное для работы лежит здесь

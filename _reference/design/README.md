# Снимок макетов Mini App

Копия утверждённых макетов из планировочной папки. Макеты здесь не правятся: новая версия приезжает новым снимком.

- `registration/` — регистрация и служебные экраны (снят 24-09-2026)
- `home/` — главный экран, шапка раздела, блоки главной (24-09-2026), экран истории (25-09-2026)
- `home/main-screen-welcome.html` + `.md` — главная новичка: слайд приветственного бонуса первым, пилюля в шапке ведёт на другой слайд; `main-screen-welcome-pill-lengths.html` — длины пилюли баланса на ширинах 320–390 (06-10-2026). Баланс в шапке всех экранов — пилюля «гранат, число, баллов» вместо «Ваши баллы» над числом; снимок экранов с балансом обновлён (06-10-2026)
- `orders/` — «Мои заказы», «Мои награды», экран заказа, экран награды (24-09-2026)
- `catalog/` — витрина, шторки офиса и подтверждения, блок каталога на главной (24-09-2026), каталог без офиса на входе (25-09-2026)
- `gifts/` — подарки от Xalq Taxi: карточка, шторка, «Забрать» (24-09-2026)
- `demo/` — демо-аккаунт: полоса над экраном и шторка «Войти как» (24-09-2026)
- `profile/` — профиль водителя, шторка сброса и шторка языка (25-09-2026)
- `staff/` — экраны сотрудника: выбор офиса, стойка, карточки заказа и награды, исходы, профиль и пароль (26-09-2026)
- `survey/` — страница опроса: экран открытия, вопросы четырёх типов со «Своим вариантом», финал, «опрос закрыт», две плашки на главной; описание словами — `survey/survey.md` (03-10-2026)
- `application/` — заявка кандидата в Mini App: экран заявки (`01-form.html`, состояния по адресу: `#filled`, `#declined`, `#old`), «Заявка принята» (`02-accepted.html`, `#call`), сбой отправки (`03-failed.html`, `#busy`), «Заявка уже отправлена» (`04-repeat.html`, `#call`); тексты на двух языках — словарь `T` в скрипте каждого макета (10-10-2026); те же четыре экрана для телефона со старым браузером — `old-01-form.html` (`#filled`, `#declined`, `#manual`), `old-02-accepted.html` (`#call`), `old-03-failed.html` (`#busy`), `old-04-repeat.html` (`#call`): старый CSS и ES5, рисует скрипт проверки движка (10-10-2026)
- `web/` — макеты веба: кодекс и дашборд, свой `README.md` (снят 04-10-2026)
- `components.md` — **карта общих элементов**: каким компонентом рисуется каждый элемент
- `system.md` — шкала шрифтов, правило цвета в строке, общие правила дизайна
- `motion.md` — движение: живой фон
- `assets/`, `covers/` — картинки, которые нужны коду или макетам отдельным файлом

Правила:

- Вёрстка идёт строго по макету: размеры, кегли, отступы, цвета и движение — из CSS макета, тексты — из словаря `T` в скрипте макета, если он есть, иначе из разметки
- Элемент из `components.md` рисуется только своим компонентом, второй способ нарисовать то же самое не заводится
- Макет приоритетнее уже свёрстанных компонентов `app/components/**/next/`: элемент тот же, а выглядит иначе — компонент правится под макет
- Листы `*-states.html`, `*-nopending.html`, `*-empty.html` — состояния экрана, а не отдельные страницы
- Ссылки в описаниях на `memory/`, `tasks/`, `product/`, `../covers/` вне этой папки и другие файлы вне снимка ведут в планировочную папку. Туда не ходить: всё нужное для работы лежит здесь

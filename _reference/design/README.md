# Снимок макетов Mini App

Копия утверждённых макетов из планировочной папки. Макеты здесь не правятся: новая версия приезжает новым снимком.

- `registration/` — регистрация и служебные экраны (снят 24-09-2026)
- `home/` — главный экран, шапка раздела, блоки главной (24-09-2026)
- `orders/` — «Мои заказы», «Мои награды», экран заказа, экран награды (24-09-2026)
- `catalog/` — витрина, шторки офиса и подтверждения, блок каталога на главной (24-09-2026)
- `gifts/` — подарки от Xalq Taxi: карточка, шторка, «Забрать» (24-09-2026)
- `demo/` — демо-аккаунт: полоса над экраном и шторка «Войти как» (24-09-2026)
- `components.md` — **карта общих элементов**: каким компонентом рисуется каждый элемент
- `system.md` — шкала шрифтов, правило цвета в строке, общие правила дизайна
- `motion.md` — движение: живой фон
- `assets/`, `covers/` — картинки, которые нужны коду или макетам отдельным файлом

Правила:

- Вёрстка идёт строго по макету: размеры, кегли, отступы, цвета и движение — из CSS макета, тексты — из словаря `T` в скрипте макета, если он есть, иначе из разметки
- Элемент из `components.md` рисуется только своим компонентом, второй способ нарисовать то же самое не заводится
- Макет приоритетнее уже свёрстанных компонентов `app/components/**/next/`: элемент тот же, а выглядит иначе — компонент правится под макет
- Листы `*-states.html`, `*-nopending.html`, `*-empty.html` — состояния экрана, а не отдельные страницы
- Ссылки в описаниях на `memory/`, `tasks/`, `product/`, `../covers/` вне этой папки и другие файлы вне снимка ведут в планировочную папку. Туда не ходить: всё нужное для работы лежит здесь

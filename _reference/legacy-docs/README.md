# XalqBonusBot — карта проекта

Документация построена по коду, скопированному с продакшн-сервера **15.08.2026**.
Состояние: код на месте, `node_modules` не установлены, локальная БД не накатана,
дамп продакшн-базы лежит в корне (`backup-db-2026-08-15-1258.sql`, ~190 МБ).

## Что это

Telegram-бот бонусной программы таксопарка **Xalq Taxi** (Узбекистан).
Водители копят баллы за выполненные поездки (данные тянутся из Yandex Fleet API)
и обменивают их на товары в физических офисах парка. Плюс купоны, акции и рассылки.

## Быстрые факты

- Node.js + Express + Telegraf 4 + Sequelize 6 + PostgreSQL 16
- ESM-исходники, транспиляция через Babel (`@babel/node` в dev, `babel build` в prod)
- Роли: `root`, `admin`, `manager`, `coupon_manager` + водитель (отдельная таблица `Drivers`)
- Прод: webhook на `/xalqbonusbot/bot`, порт из `PORT` (в `.env` — 4000)
- Крон раз в час: синхронизация поездок, автоотмена заказов, начисление бонусов
- Объём боевых данных: 4 062 водителя, 1 162 756 поездок, 715 заказов, 237 ключей переводов
